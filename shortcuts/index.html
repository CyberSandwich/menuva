Keyboard Shortcuts

键盘快捷键

Effective date: 18 March 2026 · Last updated: 19 April 2026
生效日期：2026年3月18日 · 最后更新：2026年4月19日

Navigation

KeyAction
Alt+1Go to Home
Alt+2Go to Menus
Alt+3Go to More
Left / RightPrevious / Next tab
G then HGo to Home
G then MGo to Menus
G then OGo to More
BackspaceBack to More (content pages)

Search

KeyAction
Cmd+K or Ctrl+KOpen global search
Alt+/Focus page search
Up / DownNavigate results
Alt+J / Alt+KNavigate results
EnterSelect result
EscapeClose search / clear focus
Tab / Shift+TabNavigate results (in global search)

Other

KeyAction
Alt+LToggle language (EN / Chinese)
Alt+?View this page

导航

按键操作
Alt+1前往首页
Alt+2前往菜单
Alt+3前往更多
左 / 右上一个 / 下一个标签
G 然后 H前往首页
G 然后 M前往菜单
G 然后 O前往更多
Backspace返回更多（内容页面）

搜索

按键操作
Cmd+K 或 Ctrl+K打开全局搜索
Alt+/聚焦页面搜索
上 / 下浏览结果
Alt+J / Alt+K浏览结果
Enter选择结果
Escape关闭搜索 / 清除焦点
Tab / Shift+Tab浏览结果（在全局搜索中）

其他

按键操作
Alt+L切换语言（英文 / 中文）
Alt+?查看此页面
