## 导航

| 按键 | 操作 |
|------|------|
| **Alt+1** | 前往首页 |
| **Alt+2** | 前往菜单 |
| **Alt+3** | 前往更多 |
| **左** / **右** | 上一个 / 下一个标签 |
| **G** 然后 **H** | 前往首页 |
| **G** 然后 **M** | 前往菜单 |
| **G** 然后 **O** | 前往更多 |
| **Backspace** | 返回更多（内容页面） |

## 搜索

| 按键 | 操作 |
|------|------|
| **Cmd+K** 或 **Ctrl+K** | 打开全局搜索 |
| **Alt+/** | 聚焦页面搜索 |
| **上** / **下** | 浏览结果 |
| **Alt+J** / **Alt+K** | 浏览结果 |
| **Enter** | 选择结果 |
| **Escape** | 关闭搜索 / 清除焦点 |
| **Tab** / **Shift+Tab** | 浏览结果（在全局搜索中） |

## 其他

| 按键 | 操作 |
|------|------|
| **Alt+L** | 切换语言（英文 / 中文） |
| **Alt+?** | 查看此页面 |
