如果您正在阅读这份说明，很可能您的餐厅已经被我们预先邀请加入 Menuva。若是如此，欢迎您，我们由衷地高兴您的到来。

如果您是自行发现本页的，我们同样希望与您联络。Menuva 目前采用邀请制筛选入驻餐厅，但我们始终欢迎认同我们愿景的餐厅提交自荐，详情见下方**如何申请**部分。

## 1. 为什么加入 Menuva

> Menuva 对餐厅 ==完全免费且非商业化==。无订阅费、无佣金、无需购买硬件、无需改变经营流程，且将长期保持免费。

### 活跃的用户群体

目前已有 2,000+ 用户在华威大学范围内使用 Menuva，每周都有新用户加入。加入平台后，您的菜单将直接出现在他们面前，甚至在他们决定去哪里用餐之前。

### 真实的到店流量

顾客在宿舍、步行途中或公交站就会打开 Menuva。拥有完整菜单的餐厅在平台上的曝光度明显更高，而提前浏览过菜单的顾客往往到店即可下单。

### 即时数字化的菜单

结构化的数字菜单可被搜索、筛选，并始终保持最新。您在管理后台修改价格、标记售罄或添加季节性菜品后，顾客数秒内即可看到更新。

### 一条您可分享的链接

每家餐厅都会获得一个在 `menuva.co.uk/menus` 的公开页面。可以分享到小红书、微信、Instagram、Google Maps，印在传单上，或搭配您自己的二维码使用。顾客无需下载 App 即可查看。

### 触达国际顾客

菜单自动翻译为中文，后续将支持更多语言。价格可转换为 150+ 种货币。14 种英国法定过敏原和 7 种饮食偏好均可筛选，让国际学生和有饮食限制的顾客放心点餐。

### 免部署的数据分析

查看哪些菜品最受关注、顾客从何处发现您的餐厅、最常使用的饮食筛选条件。无需自建追踪，即可了解您的客群。

## 2. 菜单创建支持

Menuva 为每家新入驻的餐厅提供 ==免费的菜单搭建服务==。这是我们推荐的方式。我们的团队会根据您提供的资料搭建初版菜单，您后续只需在管理后台做一些简单的日常维护。

### 请发送给我们的内容

| 优先级 | 信息 |
| --- | --- |
| 必需 | 每道菜的名称和价格 |
| 建议 | 主图和菜品图片 |
| 建议 | 菜品描述 |
| 建议 | 过敏原和饮食信息 |
| 建议 | 定制选项（选项名称、价格、最小/最大数量、是否必选） |
| 建议 | 食品卫生评级 |
| 建议 | 菜单分区和子分区 |

您提供的信息越详细，菜单从上线第一天起就越完整。请将以上材料发送至 [hello@menuva.co.uk](mailto:hello@menuva.co.uk)。

### 费用

免费。菜单搭建、托管、翻译、数据分析及所有平台功能目前均为免费，并将长期对餐厅免费开放。

## 3. 如何申请

### 若您已被预先邀请

请回复我们团队发给您的邮件，确认您希望加入，其余交给我们处理即可。

### 若您希望自荐加入

请发送邮件至 [hello@menuva.co.uk](mailto:hello@menuva.co.uk)，并在邮件中包含以下信息。

- **餐厅名称**
- **餐厅位置**（完整地址）
- **营业时间**
- **相关链接**（官网、Instagram、现有菜单、Google Maps 等）
- **身份证明**（营业执照、公司注册信息，或能证明您是官方代表的链接）

我们每周审核一次申请。通过后，您可以选择由我们代为搭建菜单（推荐，免费），或自行在管理后台维护。

## 4. 菜单维护方式

### 由我们代为搭建（推荐）

将菜单资料发送至 [hello@menuva.co.uk](mailto:hello@menuva.co.uk)。我们的团队会搭建初版菜单、完成翻译并上线。后续如有变动，您可以发邮件给我们，也可以自行登录管理后台更新。多数餐厅选择这种方式，因为全程免费且上线更快。

### 自行维护

如果您希望完全自主掌控，访问 [admin.menuva.co.uk](https://admin.menuva.co.uk)（需先获得访问权限），使用 Google 或任意邮箱登录，邮箱登录无需密码。后台会引导您添加餐厅、营业时间、位置和菜单项目。任何改动都会即时同步到顾客端。

## 5. 注意事项

1. Menuva 仍处于早期阶段。管理后台和入驻流程正在持续优化中。
2. 如果您遇到任何问题、发现可改进之处或发现错误，请发送邮件至 [hello@menuva.co.uk](mailto:hello@menuva.co.uk)。您的反馈将直接影响平台的发展。
