如果您是自行发现本页的，我们同样希望与您联络。Menuva 目前采用邀请制，但我们始终欢迎餐厅自荐，详情见下方**如何申请**。

## 2. 为什么加入 Menuva

> Menuva 是华威大学的一个 ==学生项目==，==目前没有任何营收，也不开展商业活动==。平台对餐厅完全免费，且将长期保持免费。

### 活跃的真实用户

已有 2,000+ 华威用户使用 Menuva，每周都有新用户加入。您的菜单将在他们决定去哪里用餐之前直接出现在他们面前。

### 真实的到店流量

顾客在宿舍、步行途中或公交站就会打开 Menuva。完整的菜单能影响他们的到店决定，让顾客到店即可下单。

### 即时更新

修改价格、标记售罄或添加季节性菜品后，顾客数秒内即可看到更新。

### 一条可分享的公开链接

每家餐厅都会获得一个在 `menuva.co.uk/menus` 的公开页面。可分享到小红书、微信、Instagram、Google Maps，或印在传单上。顾客无需下载 App 即可查看。

### 触达国际顾客

自动翻译为中文，后续将支持更多语言。价格可转换为 150+ 种货币。14 种英国法定过敏原和 7 种饮食偏好均可筛选。

### 数据分析（即将上线）

后台数据分析功能即将推出。在此之前，欢迎随时发送邮件至 [hello@menuva.co.uk](mailto:hello@menuva.co.uk) 索取报告，内容涵盖浏览量、互动数据、筛选使用情况及热门菜品。

## 3. 菜单创建支持

==每家新入驻餐厅均可享受免费的菜单搭建服务。== 我们的团队会根据您提供的资料搭建初版菜单。后续只需在菜品有变动时到管理后台做简单更新。

### 请发送给我们的内容

| 优先级 | 信息 |
| --- | --- |
| 必需 | 菜品名称和价格 |
| 建议 | 主图和菜品图片 |
| 建议 | 菜品描述 |
| 建议 | 过敏原和饮食标签 |
| 建议 | 定制选项（名称、价格、最小/最大数量、是否必选） |
| 建议 | 食品卫生评级 |
| 建议 | 菜单分区和子分区 |

信息越详细，菜单从上线第一天起就越完整。请将以上材料发送至 [hello@menuva.co.uk](mailto:hello@menuva.co.uk)。

### 费用

免费。菜单搭建、托管、翻译、数据分析及所有平台功能目前均为免费，并将长期对餐厅免费开放。

## 4. 如何申请

### 若您已被预先邀请

请回复我们团队发给您的邮件，其余交给我们处理即可。

### 若您希望自荐加入

请发送邮件至 [hello@menuva.co.uk](mailto:hello@menuva.co.uk)，并在邮件中包含以下信息。

- **餐厅名称**
- **完整地址**
- **营业时间**
- **相关链接**（官网、Instagram、现有菜单、Google Maps 等）
- **身份证明**（营业执照、公司注册信息，或能证明您是官方代表的链接）

我们每周审核一次申请。通过后，您可在以下两种方式中任选其一。

## 5. 菜单维护方式

### 由我们代为搭建（推荐）

将菜单资料发送至 [hello@menuva.co.uk](mailto:hello@menuva.co.uk)。我们会完成搭建、翻译并上线。后续有变动时，您可以邮件告知我们，或自行在管理后台更新。这是上线最快的方式。

### 自行维护

访问 [admin.menuva.co.uk](https://admin.menuva.co.uk)，使用 Google 或任意邮箱登录（邮箱登录无需密码）。后台会引导您添加餐厅、营业时间、位置和菜单项目。任何改动都会即时同步到顾客端。

## 6. 注意事项

1. Menuva 仍处于早期阶段。管理后台和入驻流程正在持续优化中。
2. 如您遇到任何问题或发现可改进之处，请发送邮件至 [hello@menuva.co.uk](mailto:hello@menuva.co.uk)。您的反馈将直接影响平台的发展。
