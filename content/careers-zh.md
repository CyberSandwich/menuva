Menuva 目前没有公开招聘任何特定职位。但我们始终在寻找优秀的人才，与我们一起打造未来全球菜单的默认平台。

## 1. 关于 menuva

**1.1** Menuva 于 2026 年 1 月 12 日在华威大学正式上线，截至撰写时已拥有超过 500 名用户。我们的目标是快速拓展至更多大学及更广泛的场景。

**1.2** Menuva 是一个由学生主导的项目，尚未注册为正式企业。加入团队不构成正式雇佣关系，也没有薪资。但你将获得参与一个拥有真实用户的真实产品的机会，积累有价值的技能，并创造切实的影响力。

## 2. 我们在寻找什么样的人

我们寻找高度积极主动、有过往主动发起项目经历的人。你不需要在任何领域成为专家，最重要的是你的学习意愿、自我提升的动力以及交付成果的能力。

### 增长方向

负责餐厅拓展和用户增长。你将与餐厅、咖啡馆、学生社团、学生会、大学部门及其他组织紧密合作，将 menuva 带给更多人、更多场所。

### 技术方向

参与产品的开发与改进。以下技术栈的经验是加分项，但不是必需的：

- React Native
- Kotlin
- Swift
- HTML、CSS、JavaScript
- Firebase
- React
- Python

## 3. 大学负责人

我们正在向其他大学拓展，寻找大学负责人来主导 menuva 在所在院校的发展。作为大学负责人，你将：

- 在当地招募和管理增长与运营团队成员。
- 推动校园内的餐厅合作与用户拓展。
- 与社团、学生会、大学部门和当地商户紧密协作。
- 代表 menuva 出席所在大学的相关活动，并参与制定拓展策略。

## 4. 如何申请

没有正式的面试流程。有意加入团队的候选人将被邀请与创始人 Duke 进行面对面交流。

请发送邮件至 [hello@menuva.co.uk](mailto:hello@menuva.co.uk)，包含以下内容：

- 你的姓名。
- 你的职位或专业，包括年级。
- 用三句话介绍你曾主导或推动的一个项目。
- 你认为相关的任何其他信息。

我们会尽快回复你。保证不会石沉大海。
