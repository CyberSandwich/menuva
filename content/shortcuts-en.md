## Navigation

| Key | Action |
|-----|--------|
| **1** | Go to Home |
| **2** | Go to Menus |
| **3** | Go to More |
| **Left** / **Right** | Previous / Next tab |
| **G** then **H** | Go to Home |
| **G** then **M** | Go to Menus |
| **G** then **O** | Go to More |
| **Backspace** | Back to More (content pages) |

## Search

| Key | Action |
|-----|--------|
| **Cmd+K** or **Ctrl+K** | Open global search |
| **/** | Focus page search |
| **Up** / **Down** or **J** / **K** | Navigate results |
| **Enter** | Select result |
| **Escape** | Close search / clear focus |
| **Tab** / **Shift+Tab** | Navigate results (in global search) |

## Other

| Key | Action |
|-----|--------|
| **L** | Toggle language (EN / Chinese) |
| **?** | View this page |
